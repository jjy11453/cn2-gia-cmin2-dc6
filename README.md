## 搬瓦工线路主要看什么

先把几个容易混在一起的概念分开。

### CN2 GIA：电信用户重点关注

CN2 GIA 的官方网络编号是 AS4809。搬瓦工官网将它描述为面向中国方向的高质量 IP Transit，主要用于改善访问中国大陆用户的稳定性，适合网站、远程办公、语音通信和其他对丢包敏感的场景。

和普通 163，也就是 AS4134，相比，CN2 GIA 的价格和容量成本更高，但拥堵情况通常更容易控制。这里的“更好”主要体现在网络路径和高峰期稳定性，不代表服务器 CPU、内存或磁盘性能自动更强。

如果你的用户主要使用中国电信，CN2 GIA 往往是选择搬瓦工线路时最先看的指标。需要注意的是，CN2 GIA 也不是一张可以保证所有地区、所有时间都满速的魔法网络。实际效果仍然需要用目标地区的测速节点验证。

### CN2 GT：名称相似，定位不同

CN2 GT 同样可能使用 AS4809，但它和 CN2 GIA 不是同一等级的产品。官网资料将 CN2 GT 归为另一种 Transit 类型，并指出它的拥塞问题可能比 CN2 GIA 更明显。

因此，看到套餐页面上写着 “CN2” 时，不要只看这三个字。需要继续确认是 CN2 GIA、CN2 GT，还是其他优化线路。很多线路争议，最开始就是因为用户把不同网络等级当成了同一回事。

### CMIN2：移动用户需要单独看

中国移动方向常见的是 CMIN2，官方页面将其标记为 China Mobile AS58807。搬瓦工对洛杉矶 USCA_9 的说明是，中国方向的流量会分别进入电信 CN2 GIA、移动 CMIN2 和中国联通 Premium 网络。

如果你使用中国移动，不能只拿电信用户的测试结果来判断。电信线路表现不错，并不自动说明移动线路也会有同样的延迟和速度。移动用户最好在购买前查看对应机房的回程路由，购买后再从自己的宽带环境进行测速。

### 联通 Premium：不要只盯着“CN2”

官网对 USCA_9 的网络说明还包括中国联通 Premium，也就是 AS10099。它和电信 CN2 GIA、移动 CMIN2 属于不同运营商的优化路径。

这也是为什么“搬瓦工线路怎么样”不能只回答一句“CN2 GIA 很好”。更准确的判断方式是：

- 电信用户重点看 CN2 GIA；
- 联通用户重点看 AS10099 等 Premium 路由；
- 移动用户重点看 CMIN2；
- 三网用户需要分别测试，不能只看单一运营商结果。

如果网站访问量不大，1 GB 或 2 GB 内存通常可以作为起点。真正影响中国大陆访问体验的，往往是线路和网站本身的缓存、图片大小、数据库查询，而不是单纯增加 CPU 核数。

线路方面，优先确认套餐是否可以使用目标机房。不要因为套餐便宜，就默认它也包含 CN2 GIA。

企业站更关心稳定性、备份、权限管理和故障恢复。搬瓦工的 KVM VPS 提供 root 权限、KiwiVM 控制面板、系统重装、快照、rDNS 和机房迁移等管理能力。

## 搬瓦工线路测试应该怎么做

购买后不要只用一次测速就下结论。线路体验会随时间段和运营商变化，比较实用的测试方式是：

### 1. 分别测试三家运营商

至少从电信、联通、移动网络各找一个节点。家庭宽带、手机热点和公司网络的出口可能不同，单个网络的结果不能代表三网。

### 2. 对比白天和晚高峰

建议在白天和晚上 20:00 至 23:00 各测试一次，重点记录延迟、丢包和下载速度。晚高峰结果更能反映线路拥堵情况。

### 3. 查看回程路由

测速数字只能告诉你快不快，不能说明为什么快或慢。使用 traceroute、MTR 等工具查看回程路径，可以确认电信是否经过 AS4809、移动是否经过 CMIN2、联通是否使用 Premium 路由。

### 4. 测试你的真实业务

如果你部署的是网站，就测试网页首屏、静态文件和后台接口。如果是远程开发环境，就测试 SSH 稳定性、代码拉取和文件传输。不要只测一个大型文件下载速度，因为它不一定代表真实业务体验。

## 搬瓦工线路的限制

CN2 GIA 和优化线路有价值，但也有边界。

首先，线路优化不能解决所有问题。源站 CPU 满载、磁盘 I/O 过高、数据库配置不当、网站没有缓存，都会造成访问慢。

其次，CN2 GIA 并不等于无限抗攻击。搬瓦工官网明确说明 CN2 GIA 容量有限，在遭遇攻击时可能需要进行 IP null-routing。 如果业务需要持续承受大规模攻击，应单独评估高防、CDN 或清洗服务。

再次，IP 质量需要单独检查。部分海外 VPS IP 可能被某些平台标记为机房 IP、代理 IP 或高风险地址。网站建站、支付、广告投放和账户登录等场景，应该提前确认目标平台的 IP 政策。

最后，搬瓦工是自管理 VPS。官网虽然提供 24/7 监控、99.9% uptime guarantee 和 30 天退款政策，但这不代表网站应用本身有人代管。
